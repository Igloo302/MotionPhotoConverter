# 更新日志

本文档记录了 Motion2Live 应用的重要变更。

## [1.2.0] - 2024-12-19

### 新增
- 支持小米 HyperOS 2、Google Pixel、三星动态照片

### 🎯 用户体验重大改进

#### 智能引导系统
- **首次使用引导** - 新增半透明引导面板，帮助用户快速了解操作方式
- **动态Live Photo图标** - 呼吸动画效果，直观展示播放功能
- **智能状态管理** - 使用UserDefaults记住用户操作习惯，引导仅在首次显示
- **平滑动画过渡** - 引导提示的淡入淡出效果，提升视觉体验

#### 触感反馈系统
- **播放开始反馈** - 轻度触感反馈(UIImpactFeedbackGenerator.light)
- **播放结束反馈** - 柔和触感反馈(UIImpactFeedbackGenerator.soft)
- **即时响应** - 与用户手势操作完美同步的触感体验

#### 交互优化
- **自然手势控制** - 按住播放，松开停止的直观操作方式
- **状态记忆功能** - 首次播放后永久隐藏引导提示
- **流畅动画效果** - 所有状态变化都有平滑的视觉过渡

### 🏗️ 架构改进

#### 组件化设计
- **PlaybackHintView组件** - 独立的引导提示视图组件
- **状态分离** - 清晰的状态变量管理(`showPlaybackHint`, `hasUserPlayedVideo`)
- **函数职责明确** - 专门的触感反馈和引导管理函数

#### 代码质量提升
- **单一职责原则** - 每个组件和函数都有明确的职责
- **可维护性** - 代码结构更加清晰，易于理解和修改
- **可扩展性** - 为未来功能扩展奠定良好基础

### 🔧 技术优化
- **异步处理优化** - 改进的错误处理机制
- **内存管理** - 更好的资源管理和清理
- **性能提升** - 优化动画和状态更新性能

### 🐛 问题修复
- 修复了编译警告和错误
- 解决了异步函数兼容性问题
- 修复了本地化字符串引用问题
- 优化了视频播放的稳定性

如需了解更多信息，请查阅项目文档或访问 GitHub 仓库。
