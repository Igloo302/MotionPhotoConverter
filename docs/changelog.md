# 更新日志

本文档记录了 Motion2Live 应用的重要变更。

## [开发中]

### 新增
- 架构重构和代码优化
- 改进的错误处理机制
- 更好的用户体验

### 修复
- 修复了编译警告和错误
- 解决了异步函数兼容性问题
- 修复了本地化字符串引用问题

## [1.0.0] - 2023-06-15

### 新增
- 首次发布
- 支持小米、Google Pixel、三星动态照片
- 支持导出为视频、Live Photo 和 GIF 格式
- SwiftUI 现代化界面
- 多语言支持（中文、英文）
- 实验室功能模块

### 技术特性
- SwiftUI + MVVM 架构
- 异步处理支持
- 完善的错误处理机制
