# 更新日志

本文档记录了 Motion2Live 应用的重要变更。

## [1.2.1] - 2024-12-19

### 🎯 华为动态照片支持
- **新增华为动态照片检测** - 支持基于 File Type Box (ftyp) 的华为动态照片识别
- **HuaweiMotionPhotoProcessor** - 专门的华为动态照片处理器
- **智能回退机制** - XMP 检测失败时自动启用 File Type Box 检测
- **品牌兼容性扩展** - 新增 `huawei` 枚举值，完善品牌支持体系

### 🐛 关键错误修复
- **修复内存对齐崩溃** - 解决 "load from misaligned raw pointer" 致命错误
  - 替换不安全的 `withUnsafeBytes` 内存访问方式
  - 使用安全的字节读取算法避免内存对齐问题
  - 添加完整的边界检查确保数据访问安全性
- **修复 PHAsset 预取警告** - 添加适当的 `PHFetchOptions` 配置
  - 消除 "Missing prefetched properties" 警告信息
  - 优化照片库资源访问性能
- **Swift 6 兼容性修复** - 解决并发安全性编译错误
  - 修复 `AVAssetExportSession` 的 Sendable 类型错误
  - 移除已废弃的 `PHFetchOptions.includeAllBurstPhotos` 属性
  - 使用 `async/await` 替代回调闭包避免数据竞争
  - 确保所有异步操作的线程安全性

### 🔧 技术改进
- **内存安全性增强** - 全面改进二进制数据处理的安全性
- **错误处理优化** - 更好的异常捕获和用户反馈机制
- **代码健壮性** - 增强边界条件处理和数据验证
- **现代 Swift 语法** - 全面采用 Swift 6 推荐的并发编程模式

## [1.2.0] - 2025-07-06

### 新增
- 支持小米 HyperOS 2、Google Pixel、三星动态照片

### 🎯 用户体验重大改进

#### 智能引导系统
- **首次使用引导** - 新增半透明引导面板，帮助用户快速了解操作方式
- **动态Live Photo图标** - 呼吸动画效果，直观展示播放功能
- **智能状态管理** - 使用UserDefaults记住用户操作习惯，引导仅在首次显示
- **平滑动画过渡** - 引导提示的淡入淡出效果，提升视觉体验

#### 触感反馈系统
- **播放开始反馈** - 轻度触感反馈(UIImpactFeedbackGenerator.light)
- **播放结束反馈** - 柔和触感反馈(UIImpactFeedbackGenerator.soft)
- **即时响应** - 与用户手势操作完美同步的触感体验

#### 交互优化
- **自然手势控制** - 按住播放，松开停止的直观操作方式
- **状态记忆功能** - 首次播放后永久隐藏引导提示
- **流畅动画效果** - 所有状态变化都有平滑的视觉过渡

### 🏗️ 架构改进

#### 组件化设计
- **PlaybackHintView组件** - 独立的引导提示视图组件
- **状态分离** - 清晰的状态变量管理(`showPlaybackHint`, `hasUserPlayedVideo`)
- **函数职责明确** - 专门的触感反馈和引导管理函数

#### 代码质量提升
- **单一职责原则** - 每个组件和函数都有明确的职责
- **可维护性** - 代码结构更加清晰，易于理解和修改
- **可扩展性** - 为未来功能扩展奠定良好基础

### 🔧 技术优化
- **异步处理优化** - 改进的错误处理机制
- **内存管理** - 更好的资源管理和清理
- **性能提升** - 优化动画和状态更新性能

### 🐛 问题修复
- 修复了编译警告和错误
- 解决了异步函数兼容性问题
- 修复了本地化字符串引用问题
- 优化了视频播放的稳定性
